### T-Stick Playground 1.0 — Setup Guide

**modulo21, 2026**

## System Requirements

- Max **9** or later  
    _(Audio effects require Max 9; the environment will still open in Max 8, but effects will not function correctly.)_

#### Installation

1. **Unzip** the file `T-Stick Playground 1.0.maxzip`.  
    This will automatically create a Max project inside your **Projects** folder:
    - **Mac:** `Macintosh HD/Users/[your username]/Documents/Max 9/Projects`
    - **Windows:** `C:\Users\[your username]\Documents\Max 9\Projects`
2. **Do not rename** the project folder or the file `T-Stick Playground 1.0.maxproj`. Renaming either will break internal dependency links and prevent the project from loading correctly.
    
    > You _can_ move the entire project folder to a different location if you like — just keep its internal structure and names intact.
    
3. **Open the project** by double-clicking `T-Stick Playground 1.0.maxproj`.  
    The **Main patch** will open automatically, displaying all the audio modules.
4. **Get started** by clicking the **Quickstart** button in the Main patch — it walks you through using the environment.

#### Support

If you run into issues during installation, double-check that:

- You're running Max 9+
- The project folder and `.maxproj` file names haven't been changed
- The project hasn't been split up or partially moved

Have fun! 🎛️
